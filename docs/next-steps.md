## Возможное развитие, не блокирующее текущий учебный план

- Настоящий источник оперативных заказов и свободных курьеров. Пока его нет, основной экран остаётся честным демонстрационным сценарием.
- Настоящее время переезда и маршруты после выбора подходящего источника.
- Автоматический откат по мониторингу после замены. Сейчас система показывает данные, решение принимает администратор.
- Развёртывание с HTTPS для доступа с других устройств вне этого компьютера. Сейчас Compose публикует веб-порт только на 127.0.0.1.

## Правила доработки

- Каждый этап доводится до работающего интерфейса и API, тестов, проверки в Docker и обновлённой документации.
- Правила мониторинга и обновления модели меняются только через новую версию правила; сохранённые решения не переписываются.
- Рабочие тома, аккаунты и журналы не очищаются; эксперименты со сдвигом данных идут в отдельном каталоге или схеме.
