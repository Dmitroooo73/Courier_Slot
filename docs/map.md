# Карта зон и погода сейчас

## Карта

Шесть зон доставки собраны из настоящих административных округов Москвы. Поэтому карта узнаётся: видны МКАД, Москва-река, выступы Митина, Бутова и Некрасовки.

| Зона | Округа |
| --- | --- |
| Центр | ЦАО |
| Север | САО + СВАО |
| Восток | ВАО + ЮВАО |
| Юг | ЮАО + ЮЗАО |
| Запад | ЗАО |
| Северо-запад | СЗАО |

Новая Москва и Зеленоград не входят в зоны: учебные заказы описывают старые границы города. Маленькие анклавы (например, аэропорт Внуково) отброшены. Общие границы упрощены вместе, примерно до 250 м, поэтому соседние зоны стыкуются без щелей.

Мощность и спрос зон по-прежнему условные и синтетические. Привязка к округам делает схему понятной, но не означает, что заказы взяты из этих округов.

Геометрия хранится в `frontend/src/geo/moscowZones.ts` (около 21 КБ), сеть для показа карты не нужна. Источник — OpenStreetMap через Nominatim, лицензия ODbL 1.0. Подпись «© участники OpenStreetMap» выводится под картой. [Условия OpenStreetMap](https://www.openstreetmap.org/copyright).

Пересобрать (нужен интернет один раз и `pip install shapely`; ответы кэшируются в `data/raw/geo/`, запросы идут с паузой 1,5 с по правилам Nominatim):

```powershell
python tools/build_moscow_map.py
```

## Погода сейчас

В строке состояния аналитических вкладок показана текущая погода в Москве с временем наблюдения, например «Сейчас в Москве +2,8 °C, пасмурно · на 16:30». Данные берутся из [Open-Meteo Forecast API](https://open-meteo.com/en/docs) через `GET /api/weather/now`.

- Сервер обращается к Open-Meteo не чаще одного раза в 10 минут, все пользователи получают общий кэш. Таймаут — 4 секунды. Пока провайдер не отвечает, повторная попытка — не чаще раза в 2 минуты, сколько бы посетителей ни пришло.
- Значение помечается устаревшим, если обновить его не удалось или если время самих данных провайдера старше 3 часов. Интерфейс тогда пишет красным «данные на …, обновить не удалось». Ошибка запроса в самом браузере тоже даёт эту пометку. Если значения ещё нет, ответ 503, и интерфейс пишет «Погода сейчас недоступна».
- `PULT_LIVE_WEATHER=0` отключает запросы, например для работы без интернета.

Эта погода только для ориентира диспетчера. Модель её не использует. Для прогноза нужен архивный погодный прогноз, доступный накануне в 20:00: он показан в карточке зоны как «Погода в прогнозе». Иначе в признаки попали бы данные из будущего.
